# 📈 Conversor de Moedas Simples em Python

Este projeto consiste em um script em Python desenvolvido como parte de uma atividade prática de programação. O objetivo do código é realizar a conversão de valores em Dólar Americano (USD) para Real Brasileiro (BRL) com base na cotação inserida pelo usuário.

## 🚀 Funcionalidades
- Interface simples via linha de comando (terminal).
- Entrada dinâmica de valores e cotação atual.
- Tratamento de erros para entradas inválidas (letras ou símbolos).
- Exibição do resultado formatado com duas casas decimais.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python 3
- **Paradigma:** Funcional / Estruturado

## 📋 Como Executar o Projeto

### Pré-requisitos
Você precisará ter o Python instalado em sua máquina. Caso não tenha, faça o download em [python.org](https://python.org).

### Passo a Passo
1. Faça o download ou clone este repositório.
2. Abra o terminal ou prompt de comando na pasta do projeto.
3. Execute o script utilizando o comando abaixo:

```bash
python script.py
```

4. Digite o valor em dólares que deseja converter.
5. Insira a cotação do dia e visualize o resultado final no console.
